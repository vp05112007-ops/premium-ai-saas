# Premium AI SaaS Website

## Overview
A fully responsive, modern SaaS website offering various AI capabilities such as conversational AI, code assistance, image generation, and resume building.

## Features
- Dynamic and responsive UI with modern glassmorphism design
- Beautiful micro-animations and transitions
- Integrated dashboard with multiple AI tools
- Pricing, auth, and profile pages

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- Three.js
- GSAP

## Running Locally

Run the following command in the terminal to start a local server:

```bash
python3 -m http.server 8080
```

Then, open your browser and navigate to:
http://localhost:8080

## Deployment

### GitHub
1. Initialize git and commit files.
2. Push to your GitHub repository.

### Vercel
1. Import the repository in Vercel.
2. The project uses standard HTML, CSS, and JS. Vercel will deploy it as a static site and apply the routing configured in `vercel.json`.
